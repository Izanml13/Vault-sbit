**Equipo BIRM:** Boubacar · Izan · Richard · Marco

## Cómo usarlo
1. Clona el repo: `git clone https://github.com/Izanml13/Vault-sbit.git`
2. En Obsidian: *Open folder as vault* → selecciona la carpeta `Vault-sbit`.
3. Empieza por [[00 - Inicio/Inicio]].
4. Antes de trabajar: `git pull`. Al terminar: `git add . && git commit -m "..." && git push`.
   (Recomendado: plugin comunitario **Obsidian Git** para hacerlo automático.)
